## 11  UI Attention Animation – **CR‑40**

A waving‑hand gif draws attention to the green chat/help button for first‑time visitors.

### 11.1  Design Requirements

* **Asset:** `wave-hand.gif` (250×180, transparent bg) saved at `/public/assets/ui/wave-hand.gif`.
* **Default state:** Visible, anchored to top‑right of the green button (‑top‑6 ‑right‑6 Tailwind offset).
* **Animation:** CSS keyframes `wave` (0°→20°→0°) 1.2 s infinite.
* **Hide Logic:** Once the user clicks the green button, set `localStorage.chatSeen=true`; component checks this flag on mount and hides thereafter.

### 11.2  Front‑End Implementation

```jsx
// components/ui/WaveHand.jsx
import { useEffect, useState } from 'react';
export default function WaveHand() {
  const [show, setShow] = useState(false);
  useEffect(() => {
    if (!localStorage.getItem('chatSeen')) setShow(true);
  }, []);
  if (!show) return null;
  return (
    <img
      src="/assets/ui/wave-hand.gif"
      alt="wave"
      className="absolute -top-6 -right-6 w-10 animate-wave pointer-events-none z-40"
    />
  );
}
```

```css
@keyframes wave {0%{transform:rotate(0deg)}50%{transform:rotate(20deg)}100%{transform:rotate(0deg)}}
.animate-wave{animation:wave 1.2s ease-in-out infinite}
```

Integrate in `ChatButton.jsx`:

```jsx
<div className="relative">
  <WaveHand />
  <button ... onClick={()=>{localStorage.chatSeen=true; openChat();}}>
    ...
  </button>
</div>
```

## 3  Database Schema Deltas (PostgreSQL)

```sql
-- users
ALTER TABLE users ADD COLUMN role user_role_enum DEFAULT 'resident';

-- profiles (already exists): add avatar_url
ALTER TABLE profiles ADD COLUMN avatar_url text;

-- residents
ALTER TABLE residents ADD COLUMN application_id uuid DEFAULT gen_random_uuid();

-- notes
ALTER TABLE notes ADD COLUMN deleted_at timestamptz;

-- attendance
CREATE TABLE attendance (
  id serial PRIMARY KEY,
  resident_id int REFERENCES residents(id),
  program_id int REFERENCES programs(id),
  status text, -- in/out
  verify_staff_id int REFERENCES users(id),
  lat double precision,
  lon double precision,
  created_at timestamptz DEFAULT now()
);

-- properties (lat/long)
ALTER TABLE properties ADD COLUMN lat double precision;
ALTER TABLE properties ADD COLUMN lon double precision;

-- settings
CREATE TABLE settings (
  id serial PRIMARY KEY,
  key text UNIQUE,
  value jsonb,
  updated_at timestamptz DEFAULT now()
);
```

## 9  Dev Workflow

1. **Branch per CR** (`feat/cr-15-profile`).
2. **PR template** must list tests added/updated.
3. **CI pipeline**: lint → Jest → Cypress → ZAP.
4. **Merge into `develop`**, tag `v1.0.0-beta`.
5. **Deploy to Replit preview**; QA runs full checklist.
6. If ✅, merge to `main`, tag `v1.0.0`, production deploy.

## 3  API Routes – Auth Suite

| Route                    | Verb  | Body                                                 | Notes                    |
| ------------------------ | ----- | ---------------------------------------------------- | ------------------------ |
| `/auth/signup`           | POST  | {first,last,email,password,role,dob,releaseDate,pin} | Returns JWT + portal URL |
| `/auth/login`            | POST  | {email,password}                                     | Returns JWT + portal URL |
| `/auth/reset/request`    | POST  | {email}                                              | emails token; 200 always |
| `/auth/reset/confirm`    | POST  | {token,dob,releaseDate,pin,newPwd}                   | 200 JWT                  |
| `/admin/users/:id/reset` | PATCH | {newPwd?}                                            | admin‑only               |
